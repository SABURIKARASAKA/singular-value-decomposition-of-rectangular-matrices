# singular-value-decomposition-of-rectangular-matrices
Реализация на Python и бенчмаркинг алгоритмов сингулярного разложения (SVD) прямоугольных матриц, включая односторонний метод Якоби, Randomized SVD и двухдиагонализацию Хаусхолдера, с применением в машинном обучении для малорангового восстановления матриц (Matrix Completion).
